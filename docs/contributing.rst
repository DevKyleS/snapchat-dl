Contributing
============

Contributions are welcome. See the
`contribution guide <https://github.com/DevKyleS/snapchat-dl/blob/main/CONTRIBUTING.md>`_
for development setup and submission guidelines.

This repository is a community-maintained fork of
`skyme5/snapchat-dl <https://github.com/skyme5/snapchat-dl>`_. Please open pull
requests for this fork against ``DevKyleS/snapchat-dl``. If your change is
intended for the upstream project, submit it to the upstream repository instead.
